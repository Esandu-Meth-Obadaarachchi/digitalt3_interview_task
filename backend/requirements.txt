# =============================================================================
# Backend dependencies - Meeting & Channel Intelligence Agent
# =============================================================================
# Direct dependencies are pinned exactly. Transitive dependencies are left to
# the resolver: pinning the whole tree would need a lock file, and for a build
# of this size the direct pins are what actually determine behaviour.
#
# Python 3.11 is required. It is the newest version with settled wheels for
# faiss-cpu, sentence-transformers and ctranslate2 on Apple Silicon.
#
# Dependencies are added in the phase that first uses them, so this file grows
# alongside the code rather than declaring an intended stack up front.
# =============================================================================
